# 3D魔方还原器

**输入真实魔方的颜色，或导入六面展开图截图，生成中文还原步骤，并跟随 3D 动画逐步操作。**

一个中文界面的三阶魔方复原工具。程序采用单文件 HTML 形式，求解引擎、截图识别与动画逻辑均已内置：下载后用浏览器打开即可使用，无需安装依赖、启动服务器或联网加载资源。

> 跟着实物还原时，建议使用魔方下方的 **“下一步”**：看清一个动作，完成后再继续。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 实物颜色录入 | 在六面展开图中逐格填色，3D 视图同步显示输入布局 |
| 截图识别 | 选择本地 PNG、JPG 或 WebP 图片，自动定位标准十字展开图并识别颜色 |
| 手动校对 | 自动识别不准时，可逐面框选、修改颜色、旋转图片或调整单面的读图方向 |
| 中心配色适配 | 导入时根据六个中心颜色建立方向映射，不强制所有布局都白色朝上 |
| 输入合法性校验 | 检查颜色数量、中心唯一性、角块与棱块组合、朝向及交换奇偶性 |
| 中文还原方案 | 同时显示转动记号与中文动作说明，支持复制公式和步骤 |
| 3D 分层动画 | 展示对应层的真实转动，支持拖动视角、滚轮缩放及重置视角 |
| 跟练控制 | 播放、暂停、上一步、下一步、回到起点与速度调节位于魔方正下方 |
| 桌面滚动吸附 | 向下滚动查看其他内容时，魔方和控制区保持在一起，方便随时暂停 |
| 离线运行 | 图片处理、输入校验与求解均在本地浏览器完成，不向服务器发送图片或布局 |

## 快速开始

### 1. 下载并打开

1. 在[仓库首页](https://github.com/jfmeng/3d-rubiks-cube-solver)下载项目压缩包并解压，或单独下载 [`index.html`](index.html) 的原始文件。
2. 用现代桌面浏览器打开本地 `index.html`。
3. 不需要执行安装命令，也不需要配置后端服务。

GitHub 的文件页面用于查看源码，不等于运行程序。请下载 HTML 文件后打开；不要把整个 GitHub 页面另存为程序。内嵌预览窗口可能限制计算线程，遇到此情况请使用独立浏览器窗口。

### 2. 先体验一次复原

依次点击：

**合法随机打乱 → 校验并计算步骤 → 播放步骤**

首次求解会在后台建立求解表，需要等待片刻。计算过程中可以取消，不需要反复点击计算按钮。

## 输入自己的魔方

### 方式一：手动录入颜色

1. 按页面的 **“当前持握”** 提示放置实物魔方，确定上、前、右三个方向。
2. 先选画笔颜色，再点击展开图中的对应格子。
3. 逐面录入全部颜色，中心格固定。每面按从左到右、从上到下读取。
4. 对照 3D 视图与实物检查，点击 **“校验并计算步骤”**。

展开图位置关系如下，每个字母代表一个完整的 3×3 面：

```text
        U 上
L 左    F 前    R 右    B 后
        D 下
```

**读图方向很重要：**

- 前、后、左、右面的上边都靠近上面 U。
- 上面 U 的第一行靠后面 B，最后一行靠前面 F。
- 下面 D 的第一行靠前面 F，最后一行靠后面 B。
- 录入后面 B 时，从魔方背后正对该面观察，并让 U 保持朝上，不要镜像抄写。
- 查看其他面时，可以暂时转动整个魔方观察，但必须保持上述面名与行列方向的对应关系。

### 方式二：上传展开图截图

1. 点击 **“上传截图识别”**，选择包含完整六面的图片。
2. 检查原图上的识别框是否准确覆盖每个面，并逐格核对右侧识别结果。
3. 自动定位失败时，点击 **“逐面框选”**，选择面名，再圈住该面完整的 3×3 外框，不要包含标题文字。
4. 颜色识别不准时，使用校对画笔修改；中心颜色也可以在此校对。
5. 红色虚线格表示需要确认。核对无误后，可点击 **“确认全部识别色”**。
6. 点击 **“导入识别结果”**，再次检查页面更新后的 **“当前持握”**，再点击 **“校验并计算步骤”**。

自动定位针对轴对齐的标准排列：上；左、前、右、后；下。图片应清晰、格子完整，尽量裁去无关内容。

支持 PNG、JPG、WebP，单张文件不超过 20 MB。导入前要求六色各 9 格、六个中心互不重复，且没有未识别或待确认格。满足这些条件不代表一定可解，后续仍需通过物理结构校验。

> “上传”仅指选择本地文件，不会将图片发送到网络。确认导入前，识别结果只存在于校对草稿中；取消不会覆盖原布局。

**适用范围：**支持平面六面展开图；不支持从单张实物透视照片自动推断被遮挡的面，也不提供实时摄像头扫描。识别后需要人工核对，程序不会为了得到解法而自动更改颜色。

## 跟随步骤还原

播放控制位于 **左侧 3D 魔方正下方**；窄屏布局中仍紧接在魔方下方。

| 控件 | 操作效果 |
| --- | --- |
| 播放步骤 | 自动执行后续动作 |
| 暂停 | 当前层转动结束后停止，避免停在半个动作上 |
| 下一步 | 只执行一个动作，适合跟着实物操作 |
| 上一步 | 动画撤回一个动作 |
| 回到起点 | 回到本次计算前的原始打乱布局 |
| 从原始布局重播 | 完成后从原始打乱状态重新演示，而不是从纯色状态继续转动 |
| 每步动画时长 | 调整转动快慢；跟练时可调慢 |
| 复制步骤 | 复制带中文说明的步骤；权限受限时可展开公式手动复制 |

**注意：**

- 还原过程中始终按“当前持握”固定上面和前面。拖动 3D 视角只改变观察角度，不会重新定义面名。
- “上一步”“回到起点”和点击公式跳转只改变网页演示，实物魔方不会同步变化。请自行撤回相应动作，或重新录入实物的当前状态。
- 进入播放后，右侧录入图保留计算前的布局，左侧 3D 显示当前进度，这是正常行为。
- 修改输入颜色会清除旧方案，避免把旧步骤用在新的布局上。

### 转动记号

| 记号 | 对应的面 |
| --- | --- |
| U | 上面 |
| D | 下面 |
| L | 左面 |
| R | 右面 |
| F | 前面 |
| B | 后面 |

- 无后缀：顺时针转 90°，如 `R`。
- 带撇号 `'`：逆时针转 90°，如 `R'`。
- 带数字 `2`：转 180°，如 `F2`。

**顺时针、逆时针均指正对正在转动的那个面观察，不是始终从魔方前方判断。** 页面会同步显示中心颜色与中文动作说明。

## 常见问题

### 为什么提示“输入需要检查”？

先检查每种颜色是否恰好 9 格，再检查各面的方向，尤其是后面和下面。即使数量正确，也可能存在重复块、错误配色、角块扭转、棱块翻转或交换奇偶性不一致。

单独扭转角块、翻转棱块或不正确的拆装可能产生无法通过正常转动还原的状态。程序会拒绝这些输入，不会输出未经验证的步骤。

### 为什么“导入识别结果”是灰色的？

通常是尚未识别全部六面、存在未知颜色或待确认格、颜色数量不正确，或中心颜色重复。请查看识别窗口中的数量统计和提示，再逐格校对。

### 首次计算比较慢，怎么办？

程序需要建立离线求解表。同一页面中的后续求解可以复用已经建立的表；刷新页面或终止计算线程后，需要重新建立。若计算超时，可取消后重试。超时不等于输入无解。

### 为什么求解成功，实物却没有还原？

请确认导入或录入的布局与实物一致，并检查是否中途改变了持握方向、把后面抄成镜像，或混淆了某个面的顺逆时针。识别到另一个合法状态时，程序无法知道它与实物不同。

建议使用“下一步”，每执行一个动作就对照实物；不确定当前进度时，重新录入比继续执行旧公式更可靠。

### 刷新后还在吗？

当前版本没有实现布局与进度的持久化保存。关闭或刷新页面后，请重新录入或导入截图；需要保留的公式可提前复制。

## 实现说明

- **界面：**HTML、CSS 与原生 JavaScript，无需构建即可运行。
- **截图识别：**本地像素颜色分类、重复方格定位与格内采样，不依赖云端识别接口。
- **求解：**内置 `cubejs 1.3.2`，采用两阶段求解，运行在 Web Worker 中。
- **结果校验：**求解后先由引擎回放检查，再用独立的贴纸空间坐标模型逐步复算，确认最后六面恢复中心颜色。
- **演示：**Canvas 透视绘制与分层旋转，使用保存的状态快照实现撤回与重播。

程序输出可执行的还原方案，不承诺最短步数，也不等同于面向初学者的层先法教学。
